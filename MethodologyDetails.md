# Methodology Documentation: Genomic Prediction of Hybrid Performance

This document outlines the statistical framework and computational implementation for predicting hybrid crop performance in Multi-Environment Trials (MET). The methodology employs Bayesian Reproducing Kernel Hilbert Spaces (RKHS) regressions to model Additive (General Combining Ability) and Dominance (Specific Combining Ability) effects, alongside their interactions with the environment.

---

## Part 1: Statistical Model Details

The framework relies on projecting parent-level genomic relationship matrices into the hybrid testing space to partition genetic variance.

### 1.1 The Base Phenotypic Model

The full multi-environment model (corresponding to Model 5 in Basnet et al., 2019) is defined as:

$$\mathbf{y} = \mathbf{1}\mu + \mathbf{X}_E \mathbf{\beta}_E + \mathbf{u}_M + \mathbf{u}_F + \mathbf{u}_{SCA} + \mathbf{u}_{M \times E} + \mathbf{u}_{F \times E} + \mathbf{u}_{SCA \times E} + \mathbf{e}$$

Where:

* $\mathbf{y}$ is the vector of hybrid phenotypes.
* $\mu$ is the overall population mean.
* $\mathbf{\beta}_E$ represents the fixed or random main effects of the environments, with incidence matrix $\mathbf{X}_E$.
* $\mathbf{u}_M$ and $\mathbf{u}_F$ are the General Combining Abilities (GCA) of the male and female parents.
* $\mathbf{u}_{SCA}$ is the Specific Combining Ability (SCA) of the cross.
* $\mathbf{u}_{M \times E}$, $\mathbf{u}_{F \times E}$, and $\mathbf{u}_{SCA \times E}$ are the Genotype-by-Environment ($G \times E$) interaction effects.
* $\mathbf{e}$ is the vector of homogeneous residual errors, where $\mathbf{e} \sim N(0, \mathbf{I}\sigma^2_e)$.

### 1.2 Kernel Construction and Hadamard Products

The genetic effects are modeled as random variables following multivariate normal distributions, governed by covariance matrices (Kernels, $\mathbf{K}$).

First, standard genomic relationship matrices ($\mathbf{G}_M$ and $\mathbf{G}_F$) are computed for the male and female inbred pools using the VanRaden method. These are projected to the observation level (hybrid $\times$ environment space) using design matrices ($\mathbf{Z}$):

* **Male GCA Kernel:** $\mathbf{K}_M = \mathbf{Z}_M \mathbf{G}_M \mathbf{Z}_M^T$
* **Female GCA Kernel:** $\mathbf{K}_F = \mathbf{Z}_F \mathbf{G}_F \mathbf{Z}_F^T$
* **Environment Kernel:** $\mathbf{K}_E = \mathbf{Z}_E \mathbf{Z}_E^T$

Interaction structures are derived natively using the Hadamard (element-wise) product ($\odot$):

* **SCA (Dominance) Kernel:** $\mathbf{K}_{SCA} = \mathbf{K}_M \odot \mathbf{K}_F$
* **GCA $\times$ Environment Kernels:** $\mathbf{K}_{M \times E} = \mathbf{K}_M \odot \mathbf{K}_E$ and $\mathbf{K}_{F \times E} = \mathbf{K}_F \odot \mathbf{K}_E$
* **SCA $\times$ Environment Kernel:** $\mathbf{K}_{SCA \times E} = \mathbf{K}_{SCA} \odot \mathbf{K}_E$

### 1.3 C++ Optimization via Eigen-Decomposition

Dense covariance matrices ($\mathbf{K}$) require $O(N^3)$ complexity for matrix inversion during Gibbs sampling, which creates computational bottlenecks for large datasets. To transition the RKHS model to a highly optimized Bayesian Ridge Regression (BRR) solver in C++, we perform an Eigen-decomposition of the kernels:

$$\mathbf{K} = \mathbf{U} \mathbf{\Lambda} \mathbf{U}^T$$

By calculating a transformed design matrix $\mathbf{Z}^* = \mathbf{U} \mathbf{\Lambda}^{1/2}$ (filtering out zero or negative eigenvalues), the model is reduced to solving linear marker effects:

$$\mathbf{u} = \mathbf{Z}^* \mathbf{\beta}$$

Where $\mathbf{\beta} \sim N(0, \mathbf{I}\sigma^2_\beta)$. This allows the C++ sampler to utilize rapid single-site updates with $O(N \times p)$ complexity.

## Part 2: BGLR Implementation Pipeline

The native R implementation utilizes the `BGLR` package, relying on its internal RKHS capabilities to map the dense $\mathbf{K}$ matrices directly.

### Module 1: Data Simulation

**Function:** `simulate_example_met_data()`

* **Purpose:** Generates a synthetic but architecturally sound Multi-Environment Trial (MET) dataset to validate the prediction pipeline.
* **Mechanism:** Simulates bi-allelic marker matrices for males and females, computes $\mathbf{G}$ matrices, and creates a full factorial design across environments.
* **Unbalancedness:** Introduces random missingness (e.g., 30% unobserved plots) to mimic real-world sparse field testing. Phenotypes are generated by sampling from multivariate normal distributions defined by the true kernel structures.

### Module 2: Predictive Space Construction

**Function:** `build_predictive_space()`

* **Purpose:** Prepares the data to predict unobserved crosses by mapping kernels across the *entire* factorial space, not just the observed trials.
* **Mechanism:** Generates a complete grid of all possible Male $\times$ Female $\times$ Environment combinations. It left-joins the observed phenotypes, resulting in `NA` values for untested crosses. Computes all $\mathbf{Z}$ matrices and the subsequent main and interaction $\mathbf{K}$ matrices based on this expanded grid.
* **Output:** Returns the full dataset and the `ETA` list required by BGLR.

### Module 3: Model Fitting & GEBV Extraction

**Function:** `fit_and_extract_gebvs()`

* **Purpose:** Executes the MCMC Gibbs sampler and extracts broad-adaptability breeding values.
* **Mechanism:** Calls `BGLR()` passing the full dataset. The sampler automatically imputes the `NA` phenotypic values by drawing from the posterior predictive distribution.
* **Extraction:** Isolates the main genetic effects ($\mu + \mathbf{u}_M + \mathbf{u}_F + \mathbf{u}_{SCA}$). Environmental main effects and $G \times E$ deviations are intentionally excluded to isolate the Genomic Estimated Breeding Value (GEBV) for selection.

### Module 4: Entry-Mean Heritability Calculation

**Function:** `calc_heritability()`

* **Purpose:** Translates plot-basis variance components into actionable entry-mean heritability metrics.
* **Mechanism:** Calculates the harmonic mean of environments per cross to account for the unbalanced design. It aggregates additive variance ($\mathbf{V}_A$) and total genetic variance ($\mathbf{V}_G$), shrinking the $G \times E$ and residual variance by the harmonic mean of testing environments, outputting both narrow-sense ($h^2$) and broad-sense ($H^2$) estimates.

### Module 5: File Management

**Function:** `clean_bglr_traces()`

* **Purpose:** Automates the removal of `.dat` files generated by the MCMC chains.
* **Mechanism:** Utilizes regex matching to identify and purge `ETA_*.dat`, `mu.dat`, and `varE.dat` files from the working directory to prevent storage bloat during cross-validation loops.

## Part 3: C++ Accelerated Implementation Pipeline

This pipeline bypasses `BGLR`, implementing a custom multi-threaded solver in C++ (`RcppArmadillo`) for massive-scale datasets.

### Module 1: Eigen-Decomposition Space Construction

**Function:** `build_eigen_space()`

* **Purpose:** Transforms the complex RKHS kernels into a linear format compatible with the C++ solver.
* **Mechanism:** Follows the same factorial design setup as the BGLR module but explicitly calls `eigen()` on $\mathbf{K}_M$, $\mathbf{K}_F$, and $\mathbf{K}_{SCA}$. It constructs a unified matrix $\mathbf{X}$ composed of the concatenated $\mathbf{Z}^*$ matrices and builds an index vector (`group_idx`) to track which columns belong to which variance component.

### Module 2: The Embedded Gibbs Sampler

**C++ Function:** `cpp_multikernel_gibbs()`

* **Purpose:** A highly optimized Bayesian Ridge Regression engine.
* **Mechanism (Step-by-Step):**
1. **Initialization:** Allocates memory using Armadillo structures (`vec`, `mat`).
2. **Intercept Update:** Samples the global mean $\mu$.
3. **Single-Site Block Update:** Iterates through every column of the $\mathbf{X}$ matrix, updating the corresponding $\beta$ coefficient conditional on all other effects.
4. **Variance Update:** Samples the residual variance ($\sigma^2_e$) and group-specific variances ($\sigma^2_u$) from an Inverse Gamma distribution.
5. **Missing Data Imputation:** At the end of each iteration, updates the unobserved phenotypes (`missing_idx`) based on the current sampled effects, allowing the missing data to seamlessly inform the next iteration.
6. **Posterior Accumulation:** Averages the samples post-burn-in.



### Module 3: Execution and GEBV Re-projection

* **Purpose:** Translates the C++ solver outputs back into biologically meaningful breeding values.
* **Mechanism:** After `cpp_multikernel_gibbs()` returns the posterior mean vectors for $\mathbf{\beta}$, the pipeline re-projects these coefficients back into the individual observation space ($\mathbf{u} = \mathbf{Z}^* \mathbf{\beta}$). It sums the components to generate the final GEBVs and ranks the entire population.

# Function details 

## 1. Data Simulation & Environment Prep

### `simulate_example_met_data()`

**Purpose:** Generates a synthetic but architecturally rigorous unbalanced Multi-Environment Trial (MET) dataset for pipeline validation.

* **Inputs:** `n_males`, `n_females`, `n_envs`, `n_markers`, `prop_missing`, `seed`.
* **Methods Implemented:**
1. **Genotype Simulation:** Randomly samples marker states $\{-1, 0, 1\}$ to populate $N \times P$ matrices for male and female inbred lines.
2. **Genomic Relationship Matrix ($\mathbf{G}$) Computation:** Implements the VanRaden (2008) method. Centers the marker matrix ($\mathbf{M}$), scales it by expected allele frequencies, computes the cross-product ($\mathbf{M}\mathbf{M}^T$), and adds a small ridge ($1 \times 10^{-4}$) to the diagonal to ensure positive definiteness.
3. **Factorial Grid Construction:** Uses `expand.grid` to create a complete target space of all possible Male $\times$ Female $\times$ Environment combinations.
4. **Unbalanced Masking:** Randomly samples a subset of indices based on `prop_missing` to simulate an incomplete crossing block, subsetting the full grid to the `observed_data`.
5. **Design Matrix Projection:** Translates categorical identities into sparse dummy matrices ($\mathbf{Z}$) using `model.matrix(~ factor - 1)`.
6. **Covariance Kernel Construction:** Computes base plot-level kernels via $\mathbf{Z} \mathbf{G} \mathbf{Z}^T$ and interaction kernels (SCA, G$\times$E) via the Hadamard product.
7. **Phenotype Synthesis:** Uses `MASS::mvrnorm` to sample true genetic and environmental effects from multivariate normal distributions defined by the respective covariance kernels. Aggregates these to formulate the final $\mathbf{y}$ vector.


* **Outputs:** A list containing `observed_data` (dataframe), `G_M` (matrix), and `G_F` (matrix).

---

## 2. BGLR-Specific Functions

### `build_predictive_space()`

**Purpose:** Constructs the statistical architecture required to predict entirely unobserved (missing) crosses using BGLR's internal missing-data handling.

* **Inputs:** `observed_data`, `G_M`, `G_F`.
* **Methods Implemented:**
1. **Full-Space Generation:** Creates a complete Male $\times$ Female $\times$ Environment grid.
2. **Phenotype Merging (NA Induction):** Left-joins the `observed_data` onto the full grid. Crosses missing from the observed trials are automatically assigned `NA` in the phenotype column.
3. **Universal Kernel Mapping:** Recalculates all $\mathbf{Z}$ incidence matrices and Hadamard interaction matrices ($\mathbf{K}_{SCA}$, $\mathbf{K}_{M \times E}$, etc.) across the *entire* combinatorial space, linking the unobserved individuals to the observed individuals via genetic covariance.
4. **ETA List Formatting:** Packages the kernels into the `ETA` list structure required by BGLR, defining the environmental main effect as Bayesian Ridge Regression (`model = "BRR"`) and all genomic/interaction kernels as RKHS (`model = "RKHS"`).


* **Outputs:** A list containing `full_data` (with `NA`s) and the `ETA` list.

### `fit_and_extract_gebvs()`

**Purpose:** Executes the BGLR MCMC engine and parses the output into actionable selection criteria.

* **Inputs:** `full_data`, `ETA`, `nIter`, `burnIn`.
* **Methods Implemented:**
1. **Gibbs Sampling Initiation:** Calls `BGLR()`. Internally, BGLR imputes the `NA` phenotypic values at every iteration by drawing from the conditional posterior predictive distribution.
2. **Vector Extraction:** Accesses the `$u` list elements within BGLR's output object, which contain the posterior means of the random effects for every plot.
3. **GEBV Aggregation:** Sums the overall mean ($\mu$), male GCA, female GCA, and SCA to compute the broad-adaptability Genomic Estimated Breeding Value, intentionally excluding G$\times$E deviations.
4. **Deduplication and Ranking:** Because main effects are identical across environments, uses `dplyr::distinct` to collapse multi-environment plots into a single row per cross, sorts descending by GEBV, and assigns a rank index.


* **Outputs:** The raw `fit` object, the ranked `hybrid_ranks` dataframe, and the `full_data` appended with GEBVs.

## 3. C++ Accelerated Functions (RKHS via Eigen-Decomposition)

### `build_eigen_space()`

**Purpose:** Transforms dense covariance kernels into linear matrices to bypass computationally expensive matrix inversions ($O(N^3)$) during MCMC sampling.

* **Inputs:** `observed_data`, `G_M`, `G_F`.
* **Methods Implemented:**
1. **Grid and Kernel Setup:** Mirrors `build_predictive_space` to construct the full combinatorial grid and base $\mathbf{K}$ matrices.
2. **Eigen-Decomposition (`get_eigen_Z`):** Calculates eigenvalues ($\mathbf{\Lambda}$) and eigenvectors ($\mathbf{U}$) of each symmetric kernel ($\mathbf{K}$).
3. **Eigenvalue Filtering:** Discards any eigenvalues $\le 1 \times 10^{-8}$ to prevent complex numbers and reduce dimensionality without losing genetic information.
4. **Feature Projection:** Computes the transformed linear design matrix as $\mathbf{Z}^* = \mathbf{U} \mathbf{\Lambda}^{1/2}$.
5. **Matrix Concatenation:** Column-binds the transformed matrices for Male GCA, Female GCA, and SCA into a single continuous $\mathbf{X}$ matrix.
6. **Group Indexing:** Creates a zero-indexed tracking vector indicating which columns in $\mathbf{X}$ belong to which variance component (necessary for grouped variance updates in C++).


* **Outputs:** A list containing `full_data`, the unified `X` matrix, `group_idx` vector, and `Z_dims` (column counts per group).

### `cpp_multikernel_gibbs()`

**Purpose:** An Armadillo-accelerated Bayesian Ridge Regression Gibbs sampler optimized for grouped variance components and native missing-data imputation.

* **Inputs:** `y` (phenotypes), `X` (eigen-transformed matrix), `group_idx`, `num_groups`, `missing_idx`, `observed_idx`, `nIter`, `burnIn`.
* **Methods Implemented:**
1. **State Initialization:** Initializes the intercept ($\mu$), effect vector ($\mathbf{\beta}$), and variance components ($\sigma^2_u$, $\sigma^2_e$). Sets up Scaled Inverse Chi-Square prior parameters ($df=5$).
2. **Intercept Update:** Subtracts the current matrix effects from $\mathbf{y}$ to isolate residuals, and samples a new $\mu$ conditional on the residual variance.
3. **Single-Site Block Update:** Iterates through every column $j$ of $\mathbf{X}$. Computes the column's specific inverse variance based on its group assignment. Calculates the conditional posterior mean for $\beta_j$ via the dot product of $\mathbf{X}_j$ and the residual vector, then samples the new $\beta_j$ from a normal distribution. Adjusts the residual vector immediately (Gauss-Seidel style update).
4. **Variance Update:** Samples the new residual variance and group-specific genetic variances from an Inverse Gamma distribution (parameterized via shape and rate dependent on the sum of squared effects).
5. **Missing Data Imputation:** Multiplies the current $\mathbf{\beta}$ vector by the rows of $\mathbf{X}$ corresponding to `missing_idx` to generate $\hat{\mathbf{y}}$. Adds random normal noise scaled by $\sigma^2_e$ to simulate the true phenotypic distribution, inserting these back into the working $\mathbf{y}$ vector.
6. **Posterior Accumulation:** After `burnIn`, adds the current states to running sum vectors, returning the averaged posterior means upon completion.


* **Outputs:** An R list containing posterior means for `mu`, `beta`, `var_u`, and `var_e`.

## 4. Analytical & Diagnostic Functions

### `calc_heritability()`

**Purpose:** Converts plot-basis variance parameters into entry-mean basis heritability metrics for breeding selection.

* **Inputs:** BGLR `fit` object, `observed_data`.
* **Methods Implemented:**
1. **Harmonic Mean Calculation:** Groups the observed data by Male and Female to count environments per cross. Calculates the harmonic mean ($N / \sum(1/x)$) to account for missing environments in the unbalanced design.
2. **Variance Extraction:** Pulls the estimated posterior mode variances (`varU`) for GCA Male, GCA Female, SCA, all three G$\times$E terms, and the residual error (`varE`).
3. **Phenotypic Variance Scaling:** Aggregates total genetic variance ($\mathbf{V}_G$). Divides the G$\times$E variance by the harmonic mean of environments, and the residual variance by (environments $\times$ reps), summing them to create the entry-mean phenotypic denominator ($\mathbf{V}_{P_mean}$).
4. **Ratio Calculation:** Computes Narrow-sense ($h^2 = \mathbf{V}_A / \mathbf{V}_{P\_mean}$) and Broad-sense ($H^2 = \mathbf{V}_G / \mathbf{V}_{P\_mean}$) estimates.


* **Outputs:** Console printout of the heritability estimates.

### `plot_model_diagnostics()`

**Purpose:** Visualizes genetic variance architecture, effect distributions, and crossover interactions.

* **Inputs:** BGLR `fit` object, `full_data`.
* **Methods Implemented:**
1. **Variance Component Extraction:** Iterates over the `ETA` list, conditionally extracting `varB` for fixed/BRR effects and `varU` for RKHS effects, mapping them to a ggplot bar chart.
2. **Distribution Melting:** Extracts the `$u` vectors for main genetic effects, uses `tidyr::pivot_longer` to flatten the data, and plots overlapping density curves.
3. **Reaction Norm Calculation:** Identifies the top 5 males by computing the mean GCA across all plots. Filters the dataset to these males, averages the G$\times$E deviations by environment, and plots line geometries to identify rank-change or magnitude-change interactions.


* **Outputs:** Renders a three-panel grid arrangement.

### `clean_bglr_traces()`

**Purpose:** System memory and storage management.

* **Inputs:** `prefix` (optional BGLR file prefix).
* **Methods Implemented:**
1. **Regex Construction:** Builds regular expressions targeting BGLR's hardcoded `.dat` file extensions (`ETA_.*\.dat`, `varE.dat`, `mu.dat`).
2. **File System Interrogation:** Scans the active working directory using `list.files(pattern)`.
3. **Execution:** Passes identified file paths to `file.remove()` to permanently delete the trace files.


* **Outputs:** Console message detailing the number of files removed.
